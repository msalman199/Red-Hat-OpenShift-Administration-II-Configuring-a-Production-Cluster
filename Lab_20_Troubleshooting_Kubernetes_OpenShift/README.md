## 🧩 Key Concepts

| Concept | Description |
|---|---|
| **kubectl / oc** | Command-line clients used to inspect logs, events, and pod status on Kubernetes and OpenShift clusters |
| **Pod Networking Issues** | Connectivity or configuration problems affecting how pods communicate within the cluster |
| **Storage Configuration Issues** | Misconfigurations in persistent volumes, claims, or storage classes that prevent pods from running correctly |
| **Resource Limits** | CPU/memory constraints on containers that, if misconfigured, can cause throttling, evictions, or crashes |
| **Troubleshooting Methodology** | Structured approach of gathering information, analyzing symptoms, implementing fixes, and verifying solutions |
| **kubectl debug** | Advanced debugging command used to attach ephemeral containers or troubleshoot running/failed pods |
| **Cluster Health Monitoring** | Ongoing tracking of cluster and workload status to catch issues proactively |
